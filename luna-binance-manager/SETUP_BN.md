# Luna Binance Manager – সহজ সেটআপ গাইড (বাংলা)

এটি আপনার **নিজের** Binance স্পট অ্যাকাউন্ট দেখার ও ম্যানুয়ালি অর্ডার/উইথড্র করার
একটি লোকাল Windows অ্যাপ। অ্যাপটি সবসময় **read-only মোডে** চালু হয়; ট্রেড বা
উইথড্র করতে হলে আপনাকে নিজে সুইচ অন করতে হবে এবং প্রতিবার কনফার্ম করতে হবে।
কোনো অটো-ট্রেডিং, অটো-উইথড্র, ক্লাউড আপলোড বা রিমোট কন্ট্রোল নেই।

## ১. Python ইনস্টল
1. https://www.python.org/downloads/ থেকে Python 3.10 বা নতুন ভার্সন নামান।
2. ইনস্টলারে **"Add python.exe to PATH"** টিক দিন। "tcl/tk and IDLE" টিক থাকবে (ডিফল্ট)।

## ২. অ্যাপ চালানো
1. `luna-binance-manager` ফোল্ডারটি কম্পিউটারে রাখুন।
2. `run_luna.bat` ফাইলে ডাবল-ক্লিক করুন। অ্যাপের উইন্ডো খুলবে।
3. টেস্ট চালাতে চাইলে `run_tests.bat` চালান (ইন্টারনেট/আসল কী লাগে না)।

## ৩. Binance-এ API key বানানো (অ্যাপ এটা করবে না, আপনাকে করতে হবে)
Binance → Profile → **API Management** → Create API।

| আপনি যা করতে চান | কী পারমিশন লাগবে |
|---|---|
| শুধু ব্যালেন্স/অর্ডার/হিস্টরি দেখা | **Enable Reading** |
| ম্যানুয়াল স্পট buy/sell/cancel | **Enable Spot & Margin Trading** |
| উইথড্র | **Enable Withdrawals** – এটা তখনই দেখাবে যখন কী-তে **"Restrict access to trusted IPs only"** দিয়ে আপনার **ফিক্সড পাবলিক IP** যোগ করবেন |

উইথড্রর জন্য আরও দরকার: Binance → Wallet → **Withdrawal Address Whitelist** চালু
করে যে ঠিকানায় পাঠাবেন সেটি আগে থেকে whitelist-এ যোগ করা। API দিয়ে শুধু
whitelist-এর ঠিকানাতেই উইথড্র হয়।

⚠️ API key/secret কাউকে দেবেন না, এই চ্যাটেও না। secret একবারই দেখায়—নিরাপদে রাখুন।

## ৪. অ্যাপে কানেক্ট
1. **Connect** ট্যাবে API key ও secret লিখুন (লেখা ঢাকা থাকে)।
2. **Live** (আসল অ্যাকাউন্ট) বা **Spot testnet** (প্র্যাকটিস; উইথড্র নেই) বেছে নিন।
3. **Connect (read-only)** চাপুন। কী মেমোরিতে থাকে, ডিস্কে/লগে কখনো লেখা হয় না।
   **Disconnect & wipe** চাপলে বা উইন্ডো বন্ধ করলে মুছে যায়।
4. কানেক্ট হলে Binance থেকে আপনার কী-র পারমিশন দেখাবে।

## ৫. দেখা (read-only)
- **Balances** – ব্যালেন্স।  **Open orders** – খোলা অর্ডার।
- **Trade history** – সিম্বল (যেমন `BTCUSDT`) লিখে Refresh।

## ৬. ম্যানুয়াল ট্রেড
1. Connect ট্যাবে **Enable manual spot trading** টিক দিন → কনফার্ম করুন।
2. **Trade** ট্যাবে সিম্বল, BUY/SELL, LIMIT/MARKET, পরিমাণ (ও দাম) লিখুন।
3. **Preview order…** চাপুন। অ্যাপ Binance-এর ফিল্টার দিয়ে যাচাই করে, `order/test`
   দিয়ে পরীক্ষা করে, তারপর প্রিভিউ দেখায়। **কনফার্ম না করলে কিছুই পাঠানো হয় না।**
4. Open orders ট্যাবে অর্ডার সিলেক্ট করে **Cancel selected…** → কনফার্ম।

## ৭. ম্যানুয়াল উইথড্র
1. Connect ট্যাবে **Enable manual withdrawals** টিক দিন → `ENABLE` লিখে কনফার্ম।
   (কী-তে উইথড্র পারমিশন না থাকলে এই সুইচ নিষ্ক্রিয় থাকবে।)
2. **Withdraw** ট্যাবে **Load coins & networks from Binance** চাপুন।
3. কয়েন ও নেটওয়ার্ক বাছুন – ফি, মিনিমাম, প্রিসিশন, memo লাগবে কি না সব Binance থেকে আসে।
4. ঠিকানা, (দরকার হলে) memo/tag, পরিমাণ লিখে **Preview withdrawal…** চাপুন।
5. প্রিভিউতে coin, network, address, memo, amount, fee, expected received দেখে
   **Continue**, তারপর আলাদা ডায়ালগে `WITHDRAW` লিখে **Submit withdrawal**।
   ক্রিপ্টো উইথড্র ফেরত আনা যায় না—ঠিকানা অক্ষরে অক্ষরে মিলিয়ে নিন।

## ৮. টাইমআউট / "UNKNOWN" হলে
নেটওয়ার্ক টাইমআউট বা Binance সার্ভার এরর হলে অ্যাপ **কখনো নিজে থেকে আবার পাঠায় না**।
অ্যাকশনটি *UNKNOWN* হিসেবে চিহ্নিত হয় এবং নতুন সব অ্যাকশন বন্ধ থাকে।
**Log / Unknown actions** ট্যাবে **Reconcile unknown actions with Binance** চাপুন—
অ্যাপ Binance-এ জিজ্ঞেস করে জানাবে অর্ডার/উইথড্র আসলে হয়েছিল কি না। তারপর আবার চেষ্টা করতে পারবেন।

## ৯. কী পরীক্ষিত, কী নয়
- ✅ মক দিয়ে পরীক্ষিত (৫৫টি টেস্ট, আসল কী বা টাকা ছাড়া): সাইনিং, হোস্ট allowlist,
  ভ্যালিডেশন, কনফার্মেশন গেট, ডাবল-ক্লিক প্রতিরোধ, টাইমআউট → UNKNOWN → reconcile, GUI ফ্লো।
- ❌ পরীক্ষা করা হয়নি: আসল Binance অ্যাকাউন্টের উত্তর, আসল অর্ডার/উইথড্র, Windows-এ `.bat` ও
  Tk রেন্ডারিং। প্রথমে Spot testnet-এ অর্ডার প্র্যাকটিস করুন, তারপর অল্প পরিমাণে লাইভ।
